TALENTLENS GUIDE

Help center

A quick guide to screening resumes with TalentLens.

1. Describe the role

Paste a job description or enter a role prompt and choose Create draft. Review and edit the generated description before screening.

2. Add resumes

Upload up to 20 PDF, DOCX, or TXT files. Each file can be up to 10 MB. Use the sample resume to try the workflow.

3. Analyze and review

Choose Analyze resumes to compare each resume with the role, then open a candidate row to inspect the summary and matched skills. Always verify against the source resume.

How are scores produced?

When configured, the server uses its selected Groq or NVIDIA model. If no provider is configured or a request fails, it uses a local keyword estimate. Scores are not hiring decisions.

Demo data and privacy

Dashboard figures and sample candidates are illustrative. Uploaded files are processed for the request and not saved between sessions. Provider-based analysis sends extracted resume text to the configured AI provider.
